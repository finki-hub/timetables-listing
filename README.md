# FINKI Hub / Timetables Listing

A timetable browser for current and historical FCSE class schedules.

## Structure

- `api/` - Cloudflare Worker API for fetching and parsing EduPage timetables
- `web/` - Vite frontend timetable browser

## API Development

```sh
cd api
npm install
npm run dev
```

## Web Development

```sh
cd web
npm install
npm run dev
```

## Build

```sh
cd web
npm run build
```
